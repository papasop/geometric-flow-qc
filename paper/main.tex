\begin{abstract}
This manuscript note records the public v0.9.4 formal audit boundary for a
six-instance numerical study of intrinsic navigation along an exact declared
response fibre in small Shor order-finding tasks. The evidence package is a
synthetic state-vector audit, not a hardware, native-gate, fault-tolerance,
cryptographic-scale, or asymptotic speedup result.
\end{abstract}

\section{Availability}

Code, the frozen protocol, complete per-meta records, reference stdout, and
integrity hashes are available in the geometric-flow-qc repository at commit
\texttt{24da8d7ea9dddb702eb07de4b567bf5637f01e51}, archived under tag
\texttt{shor-multinstance-fibre-v0.9.4}. The protocol and driver were frozen
locally before execution of the full run and archived publicly afterward; this
was not a registry-based preregistration.

\section{QPE Amplitudes}

For control-register size \(M\), exact order \(r\), Fourier component \(s\),
measurement bin \(y\), implementation parameters \(\theta\), and noise draw
\(\xi\), the phase-estimation amplitude is defined as
\[
A_s(y;\theta,\xi)=
\frac{1}{M}\sum_{x=0}^{M-1}
\exp\left[
2\pi i x\left(\frac{s}{r}-\frac{y}{M}\right)
+ i\phi_x(\theta,\xi)
\right].
\]
The final probability vector is normalized in code as numerical insurance;
that normalization is not part of the mathematical amplitude definition.

\section{Common Phase Rule}

The frozen common phase vector is generated by
\[
\epsilon^{\mathrm{common}}_j = 0.105(-0.78)^j,
\qquad j=0,\ldots,m-1.
\]
No fixed rounded four-entry vector is used as the formal definition.

\section{Budget Ledger}

The comparison uses equal composite charged ledgers, not strictly identical
task-call ledgers. Each method is charged for task evaluations and
declared-response or padding evaluations. For example, the first v0.9.4 record
has the following ledger:

\section{Claim Boundary}

Within the declared shared synthetic model family, intrinsic Euclidean ascent
along a four-dimensional exact ideal-response fibre has positive mean advantage
over the unchanged reference, equal-composite-ledger basis-invariant random
search, and equal-composite-ledger SPSA on every frozen instance. No claim is
made about native compiled circuits, hardware advantage, fault-tolerant
resources, factoring complexity, or scalability.
